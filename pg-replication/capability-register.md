# Capability register: Phases 1 and 2 (two Postgres nodes, WAL streaming, failover safety)

What this experiment has **proved**, with the evidence for each claim, and what it has **not**. A capability is listed
as proven only if it has been run and the result observed. Last evidence run: **2026-11-25** (Phase 1 remainder: the replication modes, the guards, the rejoin failure, point-in-time recovery, the hygiene and timeline checks; see the evidence log). The detail of every run (commands, numbers, defects found) is in the [evidence log](evidence-log.md).
One machine (Docker Compose, macOS), PostgreSQL 16, two nodes `pg-primary` and `pg-standby`.

**Status legend**

|---|---|

| **Proven (manual)** | Run by hand and the result recorded below; re-runnable, but no automatic pass/fail yet |

Re-run the fast checks: `bash scripts/run-all-checks.sh` (lint of all 74 shell files, the documents check, the Python standard (ruff, mypy, pytest), then the 17-step round trip).
