# Sample transcripts

These pages show the real output of four tests, so that you can see what a run looks like before you start the stack. Each page names the date and the commit of the run. A later change to a test can make a transcript out of date, so rerun the test to see the current output. The terms are in the [glossary](../glossary.md).

| Transcript | Register rows | Time |
|---|---|---|
| [Replication modes](test-replication-modes.md) | REP-04, REP-05, REP-06 | About 30 seconds. |
| [A true divergence is rewound](test-divergence-rewind.md) | FOV-09 | About 26 seconds. |
| [Automatic failover](test-auto-failover.md) | ACT-01, DET-01 | About 62 seconds. |
| [A lease stops a writer that is cut off](test-lease-fence.md) | LEASE-01 | About 70 seconds. |

Each page lists what to look for in the output. The register rows hold the number of runs and the limits.
